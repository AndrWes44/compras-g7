## Estrategia de ramas

- main: versión estable del proyecto.
- develop: integración de funcionalidades.
- feature/*: desarrollo individual de funcionalidades.

Cada integrante debe trabajar en su rama asignada.
Los cambios se integrarán a develop mediante Pull Requests.
Cuando develop esté probado y estable, se integrará a main.
